# Project structure

- `index.html`: accessible product shell and dialog markup.
- `styles.css`: responsive visual system and reduced-motion behavior.
- `app.js`: browser event wiring, rendering, language copy, and focus timer.
- `src/taskStore.js`: pure task creation, state transitions, and storage helpers.
- `test/taskStore.test.js`: behavior tests for the task model.
- `.kiro/`: project steering, spec, and automation configuration.
