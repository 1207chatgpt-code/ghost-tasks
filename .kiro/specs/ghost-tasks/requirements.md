# Requirements

## User stories

- WHEN a user enters a task title and a next step, THE app SHALL create an active ghost.
- WHEN a user refreshes the browser, THE app SHALL restore active and released ghosts from local storage.
- WHEN a user starts focus, THE app SHALL show a countdown for the selected duration.
- WHEN a user releases a ghost, THE app SHALL record completion time and show it in the release log.
- WHEN a user switches language, THE app SHALL update all visible labels between English and Chinese.

## Constraints

- No account, server, or paid API is required for the first version.
- A task title and next step are required before creation.
- The layout must remain usable on a narrow mobile viewport.
