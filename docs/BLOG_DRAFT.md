# Ghost Tasks: bringing unfinished work back to life

This post was written as part of the Kiroween 2026 hackathon.

Unfinished tasks often feel heavier than they are. Ghost Tasks turns that feeling into a small interaction: add the task, name one concrete next step, focus for a short session, and release the ghost.

The project is local-first. It uses browser storage, keeps the first version dependency-free, and includes an English/Chinese switch for a wider audience. The interface uses a midnight lantern-room metaphor so progress is visible without making productivity feel noisy.

I structured the build around a small task state model and a `.kiro` directory containing steering, requirements, design, implementation tasks, and a test hook. The most useful lesson was to keep the first workflow narrow enough to demonstrate end to end: one task, one next step, one focus session, one release.
