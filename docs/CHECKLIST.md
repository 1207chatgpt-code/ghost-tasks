# Kiroween submission checklist

- [ ] Kiro account is logged in and the exact Claude model is recorded.
- [ ] Project runs locally and the core workflow is tested.
- [ ] `.kiro/` is at the repository root and is not ignored.
- [ ] `LICENSE` is visible in the public GitHub repository.
- [ ] Public GitHub URL is verified.
- [ ] Live demo URL is verified.
- [ ] Screenshots show the real app.
- [ ] YouTube video is public or unlisted without a password and under three minutes.
- [ ] `docs/KIRO_USAGE.md` contains only actual Kiro usage.
- [ ] Blog and social drafts are reviewed and published by the user if desired.
- [ ] Devpost draft is saved and the category is Costume Contest.
- [ ] Final Devpost submission is reviewed by the user before submitting.
